# Phase 4 gate: the requester transcript through Hermes (2026-09-26)

The gate, from AOR roadmap/14 §9 Phase 4: *the same requester transcript
from Discord through Hermes on ms01 gives the same result, with no step
dropped.* **PASS.** One Discord conversation filed AGADMIN-11, a story under
epic AGADMIN-6, in Backlog with `needs-review` and four Given/When/Then
criteria. Every step of the Phase 3 story gate ([run 2](2026-09-24-phase3-gate.md))
happened, in the same order.

This is a summary. The request and the items' text are board content, so
they stay out of git. The raw session is in `transcripts/raw/`, which is
gitignored and kept on ms01.

## Setup

- **Host:** Hermes Agent in Docker on ms01 (upstream build
  `v2026.7.1-691-g838d50495`), in a dedicated `po` profile with its own
  gateway and Discord bot. In Discord the bot is limited to one channel.
  The profile is [examples/hermes/config.fragment.yaml](../examples/hermes/config.fragment.yaml)
  with ms01's paths. The repo is mounted read-only into the container, and
  `uv run` starts the server there, with its venv under the profile.
- **Model:** Opus 5.5 (`claude-opus-5-5`), the model Phase 3's Claude Code
  session ran, so the host is the only change.
- **Framing:** the profile's `SOUL.md` is the README's framing line
  ([examples/hermes/SOUL.md](../examples/hermes/SOUL.md);
  [tests/test_examples.py](../tests/test_examples.py) ties the two). The
  session's stored system prompt had the line, the four skills in its skill
  index, no Hermes default identity and no memory block.
- **Tools:** `clarify`, `skills` and the board server's 11 tools, and
  nothing else: no shell, files, web, delegation or memory. Hermes has no
  permission prompt for MCP tools, so, unlike Phase 3, `commit_item` had no
  second guard. The skill's own yes was the only one.
- **Board:** Plane, throwaway project `AGADMIN`, `confirm = "always"`,
  `item_case = "title"`. The token comes from the profile's `.env`, not
  Bitwarden: the gateway is always on, and a locked vault session would stop
  it (Phase 3's "locked secret" finding).
- **Requester:** Chris, @mentioning the bot with a plain request that
  follows up the Phase 3 weekly-planning work. Hermes opened a thread, and
  the conversation continued there with no tracker terms.
